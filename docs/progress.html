Phase 2

Real-time protection (user mode)

In progress6 / 12 · 50%
  • File shield: Downloads, Desktop and Startup folders, scanned as files finish writing
  • Process shield: every program scanned as it starts
  • Auto-quarantine of confirmed threats (process stopped first); suspicious finds wait for the user
  • ClickFix shield: scores copied commands, replaces clear-cut lures on the clipboard
  • Run-dialog (Win+R) history check for past ClickFix commands
  • Stealer shield: flags non-owners opening browser, Discord, Telegram and wallet secrets (Restart Manager)
  • Background service so shields run without the app open
  • AMSI provider: PowerShell, VBScript, JScript and macros checked as they run
  • Download watcher with Mark-of-the-Web; copy it onto files extracted from archives
  • Suspicious process chains (browser/Office starting mshta, wscript, powershell -enc, regsvr32 /i:http)
  • Vulnerable-driver blocklist (Microsoft list + LOLDrivers); alert on new kernel drivers
  • Quiet mode for games; low-priority scanning; performance budget (AV-Comparatives impact ≤ 10)
